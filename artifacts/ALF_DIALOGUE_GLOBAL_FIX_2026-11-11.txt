1. Go to the "GLUE" menu.
2. For manual glue application:
   - Use the "Manual droplet feed" button to test glue application.
   - Check the droplet shape, size, and placement.
   - Adjust the heads, pulse duration, and offset if needed.

   - Enable "Droplets at winding end" function in the "GLUE" menu.
   - Set the nozzle operation time for the required droplet size.
   - Adjust the droplet offset relative to the knife.
   - Perform a test cycle to verify tail fixation.

4. To adjust glue application timing:
   - Move sensor S61 along the knife cylinder path:
     - Closer to the end of stroke for later application
     - Closer to the start for earlier application
   - After speed changes, perform test applications and correct the position.
