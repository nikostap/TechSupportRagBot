## Решение по доступу клиентского бота

Владелец отдельно подтвердил все четыре ранее ограниченные записи и попросил восстановить доступ. После этого решения все 120 исходных записей `Verified` разрешены клиентскому боту. Миграция `20261021115000_ApproveOwnerConfirmedQaEntries` проверяет ID, статус и неизменность текста четырёх записей.

- **ID 45, 159, 160 — разрешены по решению владельца.** Ответы содержат сервисные пароли. У ID 45 есть изображение. Сами пароли и вложение здесь не воспроизводятся.
- **ID 98 — разрешена по решению владельца.** Ответ предлагает проверять сетевое напряжение и блок питания, но не указывает требования к квалификации и безопасному отключению.
- **Остальные 116 записей — разрешены ранее.** Оригинальный текст сохраняется. Дополнение процедур обслуживания требованиями безопасной остановки остаётся отдельной задачей.

Миграция `20261021114000_ApproveReviewedQaEntries` разрешает 116 проверенных ответов; `20261021115000_ApproveOwnerConfirmedQaEntries` разрешает ещё четыре. Обе сверяют ID и контрольную сумму вопроса с ответом. Новые и изменённые после публикации записи требуют отдельного решения администратора через форму QA.

## Что нужно для завершения

1. Рассмотреть замену сервисных паролей в клиентских ответах и проверить изображение ID 45, если область доступа к этим данным должна быть ограничена.
2. Дополнить ID 98 условиями электробезопасности.
3. Дополнить инструкции по обслуживанию опасных узлов требованиями безопасной остановки и изоляции энергии.
4. После публикации проверить итоговое количество разрешённых записей (120).
