# Инструкции для работы с репозиторием

Перед изменениями интерфейса, маршрутов, прав, RAG или инфраструктуры прочитать `PROJECT_MAP.md`.

Если задача меняет страницы, вкладки, права доступа, ключевые сценарии, модели данных, AI-провайдеров или deployment, обновить `PROJECT_MAP.md` в рамках той же задачи. Не оставлять карту устаревшей.

Реальные ключи находятся в `.env`: не переносить их в документацию, код, логи или ответы.

Новые и изменяемые слова интерфейса добавлять только через общий словарь `TechSupportRagBot/Services/UiText.cs`: для каждого ключа указывать русский и английский варианты. Не записывать пользовательские подписи, подсказки, сообщения, заголовки и `aria-label` напрямую в Razor, JavaScript или C#; вызывать `UiText.T(...)` или передавать в JavaScript переводы из словаря. Перед завершением изменений проверять обе локали.
